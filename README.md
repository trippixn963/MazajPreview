# مزاج · Mazaj

**A 24/7 ambient Arabic lo-fi station, living in one Discord voice channel.**

<img src="assets/divider.png" width="420" alt="">

`Python 3.12` · `discord.py` · `Lavalink` · `WebSocket` · `React`

**[Live station page →](https://trippixn.com/Mazaj)**

<div align="center">

### The control panel

<img src="assets/panel.png" width="720" alt="Mazaj control panel">

A live Components V2 card — fixed art, a gold progress bar built from six
custom emoji, a running timer, and a footer crediting whoever last changed the
track. It refreshes every eight seconds and re-posts itself below new messages,
so it is always the last thing in the channel.

</div>

<img src="assets/divider.png" width="100%" alt="">

<div align="center">

### Picking a mood

<img src="assets/selector.png" width="720" alt="Track selector">

Six hours of Fairuz, George Wassouf, Kadim Al Saher and Elissa. Bilingual
labels, real durations read off the loaded files, one swap per person every ten
minutes — because a single dropdown changes what the whole room hears.

</div>

<img src="assets/divider.png" width="100%" alt="">

<div align="center">

### Arrivals

<img src="assets/welcome.png" width="760" alt="Welcome card">

Mentioned on the way in, never on the way out. Lifetime listening time is
tracked across restarts, and the figure is hidden entirely on a first visit —
`0s` is a worse greeting than none. Self-deletes after ten minutes.

</div>

<img src="assets/divider.png" width="100%" alt="">

<div align="center">

### Presence and status

<img src="assets/voice.png" width="440" alt="Voice channel status">
&nbsp;&nbsp;
<img src="assets/presence.png" width="300" alt="Rich presence">

Sixteen bilingual mood lines rotate on the channel status every ten minutes.
The rich presence mirrors whichever one is showing — English half only, emoji
kept — so the two can never drift apart and display different moods at once.
Idle, not online: the yellow moon is what a station sitting quietly looks like.

</div>

<img src="assets/divider.png" width="100%" alt="">

<div align="center">

### The profile

<img src="assets/profile.png" width="620" alt="Bot profile">

The banner mirrors a live server-stats render shared with a sibling bot, so
every bot in the server shows the same member count. The bio's icons are
generated in-house on the same gold pipeline as the progress bar.
